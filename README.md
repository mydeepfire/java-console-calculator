# Консольный калькулятор на Java

Практическая работа №1. Консольное приложение-калькулятор с поддержкой непрерывных вычислений, обработкой исключений и сквозными командами управления.

## Возможности

* **Базовые арифметические операции:** сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`).
* **Непрерывные вычисления:** результат предыдущей операции автоматически становится первым операндом для следующей.
* **Сквозные команды управления (без учёта регистра):**
    * `C` / `c` — сброс текущего результата и возврат к началу вычислений (доступно на любом шаге ввода).
    * `S` / `s` — штатное завершение работы программы (доступно на любом шаге ввода).
* **Гибкий ввод дробных чисел:** поддерживается ввод как через точку (`3.5`), так и через запятую (`3,5`).
* **Защита от некорректного ввода:**
    * обработка `NumberFormatException` при вводе нечисловых данных;
    * проверка деления на ноль с сохранением предыдущего результата;
    * валидация вводимого оператора.

## Требования и запуск

* **Java:** JDK 11 или выше.

### Компиляция и запуск из терминала

```bash
javac Calculator.java
java Calculator
```

```text

Команды управления (доступны на любом шаге): C — сброс, S — выход.

Введите операцию (+, -, *, /) или команду (C, S): *
Введите второе число (или C/S): 2
Результат: 21.0
Введите операцию (+, -, *, /) или команду (C, S): /

Результат сброшен.
Введите первое число (или C/S): s
Завершение работы калькулятора.
```

## Структура проекта

* `Calculator.java` — основной класс приложения с точкой входа `main`, методами валидации ввода и изолированными методами математических операций (`add`, `subtract`, `multiply`, `divide`).
